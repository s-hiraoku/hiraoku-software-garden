# ドキュメント案内

ソフトウェアガーデンの基本方針を定めた正式文書は、[ソフトウェアガーデンの思想](philosophy.md)です。

## 読む順番

1. [プロジェクト概要](../README.md) — 目指すソフトウェアファクトリーと、このリポジトリの役割。
2. [ソフトウェアファクトリーの参考資料](references/README.md) — 実践事例、公開仕様、検証と出荷の手法、共有資料。
3. [ナーサリーの設計と使い方](implementation/README.md) — 共通の開発手順、リポジトリの登録とチェック実行。
4. [用語集](../GLOSSARY.md) — 人とエージェントで用語の意味をそろえるための定義。
5. [ソフトウェアガーデン設計書](implementation/design.md) — 仕様を起点とする実行・検証の流れとテンプレートの運用方針。

## 資料の置き場

| 場所 | 内容 |
| --- | --- |
| `references/` | 参考資料一覧、横断メモ、共有資料 |
| `references/cases/` | 公開仕様や実践事例 |
| `references/sources/` | 講演の原文・訳文・要約などの保存資料 |
| `references/methods/` | 仕様の定義、形式検証、出荷と改善の手法 |
| `implementation/` | 共通基盤の設計、使い方、今後の実装 |

外部資料の記述と、ソフトウェアガーデンで採用した仕様を区別します。実装・検証が済んでいない内容を完了扱いにはしません。
